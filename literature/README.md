# Литература проекта

Одна статья — один файл в `papers/`, поэтому нет конфликтов при слиянии.

## Как добавить статью

1. Скопируйте `_template.md` в `papers/ГОД-автор-слово.md`, например `papers/2022-sun-knn.md`.
2. Заполните шапку и закоммитьте. Если читать некогда, оставьте `status: to-read`.
3. Прочитали статью — впишите себя в `read_by`, обновите `status` и `useful`, добавьте заметки.

## Поля

| Поле | Значения |
|---|---|
| `title` | название |
| `url` | ссылка (arXiv, openaccess, DOI) |
| `added_by` | кто добавил |
| `read_by` | кто читал, списком: `[otto, masha]` |
| `status` | `to-read` — не читали, `abstract` — только аннотация, `full` — полный текст |
| `useful` | `yes`, `no`, `?` |

Цифры в заметках пишем только с местом в статье (`Табл. 3`).

## Отчёт

```
python scripts/lit_index.py           # проверить карточки и собрать index.md
python scripts/lit_index.py --check   # только проверить
```

`index.md` собирается автоматически, руками его не правим.

# Frozen router: B0/B2, F2/F3 and geometry

Эксперименты на Tesla T4, 25 октября 2026. B0 и B2 заморожены; обучались только селекторы.

## Файлы

- `router.ipynb` — исходный ноутбук с сохранёнными выводами.
- `router-github-ready.zip` — полный снимок из 137 файлов: код, веса, статистики, разбиения, результаты, bootstrap, логи и описание методики. Для восстановления распаковать в корень отдельного рабочего клона этой ветки.
- `router_results.zip` — исходный архив финальных результатов.
- `routing_v1_stage1.zip` и `routing_v1_stage1.sha256` — исходная резервная копия первого этапа и проверенная контрольная сумма.
- `routing_v1_environment.txt` — окружение DataSphere.
- `repeat_comparison.csv` — сравнение двух замеров P1.

Внутри полного снимка описание: `docs/frozen_router_results.md`; контрольные суммы: `artifact_sha256.json`. Исходные изображения Cityscapes и большие покадровые кэши не передавались и не включены.

## Результаты P1 (200 кадров)

| Метод | mIoU | Окон/кадр | Повторное среднее время, мс |
|---|---:|---:|---:|
| ridge_base | 79.7910 | 2.825 | 462.8290 |
| mahalanobis_F3 | 79.6743 | 2.715 | 967.3994 |
| raw_entropy | 79.9009 | 2.735 | 380.9597 |

В повторе матрицы ошибок и число окон совпали для каждого кадра. Среднее время изменилось менее чем на 0.24%. Это проверка воспроизводимости на тех же данных, не независимый тест.

Выигрыш Mahalanobis F3 +0.571 п.п. относительно ridge_base на внутренней validation не перенёсся на P1. Энтропия остаётся предпочтительным проверенным роутером. P1 использовалась ранее: результаты исследовательские. Одинаковое число окон не означает одинаковое полное время.

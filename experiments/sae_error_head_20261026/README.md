# SAE: обнаружение ошибок замороженной B0

Cityscapes, 240 кадров train и 60 внутренней validation; seed 0. B0/B2 заморожены. Сравниваются уверенность, F2/F3, их объединение и совместная голова с разреженным автоэнкодером. P1 во втором эксперименте автоматически не запускалась.

## Архитектура SAE

Нормализованные F2/F3 приводятся к 128×256 и объединяются в 224 канала. Энкодер: Conv1×1(224→16), ReLU. Декодер: Conv1×1(16→224). Классификатор получает 16 латентных каналов, карту ошибки реконструкции и 3 карты уверенности. Всего 10081 параметр. Совместная потеря: BCE + 0.1 reconstruction MSE + 0.001 mean(abs(z)). AdamW, lr=0.001, weight_decay=0.0001, batch=1, максимум 8 эпох; выбор по validation BCE. OHEM выключен.

В выбранных настройках активации и SAE не превзошли энтропию. Это один seed на внутренней validation, без сквозного замера времени; AP и mIoU — разные метрики. Геометрические расстояния в латентном пространстве SAE не проверялись.

## Восстановление

В отдельном рабочем клоне сначала восстановите базовый код из `../frozen_router_20261025/router-github-ready.zip` в корень репозитория, затем распакуйте новый `frozen-error-head-v1.zip` и архив результатов с сохранением относительных путей. Исходные изображения и большие покадровые кэши не входят в архивы и нужны отдельно для повторного обучения. Пути DataSphere в конфигурациях нужно адаптировать при переносе.
